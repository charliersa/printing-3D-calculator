# FilaCost × Google Sheets 雲端資料庫設定

FilaCost 後台的資料(線材、機台、訂單、客戶、商品、電價與計算機參數)可以存到你自己的 Google 試算表。
網頁透過試算表內的 Apps Script 讀寫資料,不需要另外架伺服器。

## 一、建立試算表 API(約 5 分鐘)

1. 到 [Google 試算表](https://sheets.google.com) 建立一個新的空白試算表,例如命名「FilaCost 資料庫」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪除編輯器裡預設的 `function myFunction() {}`,把本資料夾的 [`Code.gs`](Code.gs) 全部內容貼上,按 **儲存**。
4. 上方函式下拉選單選 **`setup`**,按 **執行**。
   - 第一次會要求授權:選你的帳號 → 「進階」→「前往(不安全)」→ 允許。這是你自己的指令碼,只會存取這份試算表。
   - 執行完後,下方「執行記錄」會出現 `存取金鑰 API_TOKEN:xxxxxxxx`,**複製這串金鑰**。
   - 回到試算表,會看到已建立 `線材`、`線材類型`、`廠商`、`機台`、`固定成本`、`訂單`、`客戶`、`商品`、`電價級距`、`設定` 工作表。
5. 右上角 **部署 → 新增部署作業**:
   - 類型(齒輪圖示)選 **網頁應用程式**
   - 執行身分:**我**
   - 誰可以存取:**所有人**
   - 按 **部署**,複製 **網頁應用程式網址**(結尾是 `/exec`)。

## 二、在 FilaCost 後台連線

1. 開啟 `index.html` → 進入後台 → **參數與預算**。
2. 在「Google Sheets 雲端資料庫」填入:
   - **Apps Script 網頁應用程式網址**:第 5 步複製的 `/exec` 網址
   - **存取金鑰**:第 4 步複製的 API_TOKEN
3. 按 **測試連線**,出現「連線成功」即可。
4. 第一次連線請按 **上傳全部到雲端**,把目前資料寫入試算表。
   (若「自動同步」是開的,重新整理頁面時也會發現試算表是空的並自動上傳。)

## 同步規則

| 時機 | 行為 |
|---|---|
| 開啟頁面(自動同步開) | 從試算表載入所有資料,覆蓋本機 |
| 在後台修改任何資料 | 約 1.5 秒後,只上傳有變動的工作表 |
| 上傳失敗(斷網等) | 變更保留在本機,下次修改時一併重試 |
| 按「從雲端載入」 | 立即以試算表內容覆蓋本機 |
| 按「上傳全部到雲端」 | 立即以本機內容覆蓋整份試算表 |

- **可以直接在試算表編輯資料**(改價格、加客戶等),回到網頁重新整理或按「從雲端載入」即可看到。第一列欄位名稱請勿更改。
- 某張工作表若是空的,載入時會保留本機資料(不會把本機清空)。
- 多人同時編輯時以「最後寫入」為準;開始工作前先重新整理頁面以取得最新資料。
- `_extra` 欄是系統保留欄位,請勿修改。

## 工作表對照

| 工作表 | 內容 | 備註 |
|---|---|---|
| 線材 | 共用線材庫:品牌、類型、顏色、定價、淨重、庫存… | `tiers` 為量販折扣 JSON |
| 線材類型 / 廠商 | 計算機線材後台的類型與廠商清單 | |
| 機台 | 機台名稱、型號、購入價、壽命、功率、耗材率、狀態 | |
| 固定成本 | 計算機固定成本項目 | `per`:unit 每件 / order 整筆 |
| 訂單 / 客戶 | 訂單與客戶名冊 | |
| 商品 | 前台商品目錄 | |
| 電價級距 | 台電累進級距(夏月 / 非夏月) | |
| 設定 | 計算機目前案件參數、預設值、報價附註 | value 為 JSON |

## 安全性

- 存取金鑰只存在你的瀏覽器(localStorage)與 Apps Script 的指令碼屬性中,不會寫進網頁原始碼。
- 任何取得「網址 + 金鑰」的人都能讀寫這份試算表,請勿公開分享。需要更換時,在 Apps Script 執行 `resetToken()`,再到後台貼上新金鑰。

## 修改 Code.gs 後

Apps Script 修改後需要重新部署才會生效:**部署 → 管理部署作業 → 編輯(鉛筆)→ 版本選「新版本」→ 部署**。網址不變。
